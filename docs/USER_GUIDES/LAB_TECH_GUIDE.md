# CareSmart Laboratory Technician Quick Reference Guide

This guide covers sample phlebotomy collection, result entry, and critical panic value handling.

---

## 1. Phlebotomy & Sample Collection
1. Log in and open **Lab**.
2. Select orders marked **PENDING_SAMPLE**.
3. Verify patient identity via Patient ID and full name.
4. Click **Collect Sample**. The system generates a unique barcode (e.g. `SMP-984210`).
5. Affix barcode sticker to the test tube or specimen vial.

---

## 2. Result Entry & Panic-Value Flags
1. For orders marked **SAMPLE_COLLECTED**, click **Enter Results**.
2. Enter values for each parameter (e.g. Hemoglobin, Total WBC, Platelets).
3. The system checks findings against age/gender biological reference ranges.
4. **Critical / Panic Values:**
   - If a result is severely abnormal (e.g., Hemoglobin < 7 g/dL or Platelets < 20,000), check **Mark as Critical / Panic Value**.
   - This sends an urgent SMS notification to the treating physician.
5. Click **Sign Report & Publish** (or save draft). Once signed, the report becomes immediately available on the Patient Portal.
